# 📚 书签管理器 - Flask Mini Project

一个简洁实用的个人书签管理系统，基于 Flask 开发。

## ✨ 功能特性

- ✅ **添加书签**：保存网页标题、URL、描述和标签
- 🔍 **智能搜索**：支持按标题、URL、描述全文搜索
- 🏷️ **标签管理**：使用标签分类组织书签，支持标签筛选
- ✏️ **编辑功能**：修改已保存的书签信息
- 🗑️ **删除功能**：移除不需要的书签
- 📱 **响应式设计**：适配桌面和移动设备
- 🎨 **美观界面**：现代化渐变背景和卡片式布局

## 🛠️ 技术栈

- **后端**：Flask 3.0.0
- **数据库**：SQLite (Flask-SQLAlchemy)
- **前端**：HTML5, CSS3, 原生 JavaScript
- **样式**：自定义 CSS（无需额外框架）

## 📖 使用说明

### 添加书签

1. 点击导航栏的"+ 添加书签"按钮
2. 填写书签信息：
   - **标题**（必填）：网页标题
   - **网址**（必填）：完整的 URL（可以省略 https://）
   - **描述**（可选）：对书签的简短描述
   - **标签**（可选）：用逗号分隔多个标签，例如：`前端, React, 教程`
3. 点击"保存书签"

### 搜索书签

在首页搜索框输入关键词，系统会在标题、URL 和描述中查找匹配的书签。

### 标签筛选

点击任意标签按钮，可以筛选出包含该标签的所有书签。

### 编辑和删除

每个书签卡片右上角有编辑（✏️）和删除（🗑️）按钮：
- 点击编辑按钮修改书签信息
- 点击删除按钮会弹出确认对话框，确认后删除

## 🎯 核心特性说明

### 数据库模型

- 使用 SQLite 数据库存储书签
- 自动记录创建时间和更新时间
- 支持标签的逗号分隔存储和列表转换

### URL 自动处理

系统会自动为没有协议的 URL 添加 `https://` 前缀。

### 消息提示

所有操作都有友好的成功/错误提示消息，5 秒后自动消失。

## 🔧 配置说明

应用配置位于 `app/__init__.py`：

```python
app.config['SECRET_KEY'] = 'dev-secret-key-change-in-production'
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///bookmarks.db'
```

**⚠️ 生产环境部署时，请务必更改 SECRET_KEY！**
